# 🧲 전자기력 실험실

중학교 2학년 과학 「Ⅱ. 전기와 자기」 — **전류가 만드는 자기장 · 자기장 속 도선이 받는 힘(전자기력) · 전동기**.

성취기준 **[9과14-04]** 자기장 안에 놓인 전류가 흐르는 코일이 받는 힘의 특성을 추리하고, 전동기 등 일상생활에서 활용한 예를 찾을 수 있다.

## 실험실 장면

- **🧭 전류가 만드는 자기장** — 직선 도선 둘레의 나침반(⊙ → 반시계, ⊗ → 시계), 코일의 N극.
- **⚡ 도선이 받는 힘** — 알루미늄박 실험. 전류 방향 · 자석의 극 · 저항 · 자석 수를 바꿔 힘의 **방향과 크기**를 본다.
- **🌀 전동기** — 코일의 두 변 AB · CD 가 반대로 힘을 받아 돈다. 정류자가 반 바퀴마다 전류를 끊는다.
- **🏆 미션 8개** — 예측 → 확인 → 이유 공개.

## 이 앱의 결론

1. 전류가 흐르는 도선 **주위에도 자기장**이 생긴다.
2. 자기장 속의 전류는 **힘**을 받는다. **방향**은 전류와 자기장이 정하고, **크기**는 전류와 자기장의 세기에 **비례**한다.
   전류·자기장 중 **하나만** 바꾸면 방향이 뒤집히고, **둘 다** 바꾸면 그대로다.
3. **전동기** — 코일의 두 변은 전류가 반대라 힘도 반대 → 코일이 **회전**한다.
